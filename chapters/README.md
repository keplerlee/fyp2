更新流程：先更新对应章节的 Markdown 正文，再将同一版本写入仓库根目录的 `FYP Thesis Template.docx`，完成后更新本表状态。Markdown 与 Word 不会自动同步，需要在每次修改时执行同步和核对。未开始的章节不创建空白占位文件。

Markdown 文件也是纯文本，可以用普通文本编辑器打开；需要 `.txt` 时从对应 `.md` 导出，避免维护两份独立正文。全篇共用的参考文献仍放在 Word 的 References 中，引用核对和待确认事项见根目录 `Chapter1_Review_Notes.md`。

`/tmp/fyp-review/` 仅用于临时提取和检查，不作为后续章节的保存位置。仓库内文件保存在云工作区；若要在 GitHub 或本地电脑获取，还需推送或下载。
